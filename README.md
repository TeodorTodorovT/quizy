# Quick Quizy

A modern, responsive quiz application built with React and TypeScript. Test your knowledge across various categories with this interactive quiz app.

## Live Demo

[Try Quick Quizy](https://quick-quizy.vercel.app/)

## Features

- Multiple quiz categories
- Difficulty selection
- Customizable number of questions
- Real-time score tracking
- Responsive design for all devices
- Clean and intuitive UI

## Technologies Used

- React 18
- TypeScript
- Vite
- TailwindCSS
- Axios
- [Open Trivia DB API](https://opentdb.com/)

## Local Development

1. Clone the repository
```bash
git clone https://github.com/TeodorTodorovT/quizy.git
cd quizy
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

## Usage

1. Select your preferred quiz category
2. Choose difficulty level (Any, Easy, Medium, Hard)
3. Set number of questions (3-50)
4. Click "Start Quiz" to begin
5. Answer questions by clicking on your chosen option
6. View your final score and play again!
